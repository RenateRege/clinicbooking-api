# ClinicBooking API

Simple JavaScript backend learning project, inspired by clinic booking systems and osteopathy practice.

The project was built to practice core backend concepts in JavaScript before moving on to Express, REST APIs and databases.

## Features

### Patients
- View all patients
- Find patient by ID
- Add new patients

### Appointments
- View appointments
- View appointments for a specific patient
- Add new appointments
- Update appointments
- Delete appointments

## Concepts Practiced

- JavaScript
- Arrays
- Objects
- Functions
- CRUD operations
- Data relationships
- Array methods:
 - find()
 - filter()
 - forEach()
 - push()
 - splice()
